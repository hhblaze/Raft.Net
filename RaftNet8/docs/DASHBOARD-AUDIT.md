## Measurement limits

The [final SDK8 matrix](../benchmarks/results/dashboard-final-sdk8-2026-11-15.html) passes12/12 median comparison controls after ten pairs/cell. On/baseline throughput is−1.87…+1.83%, allocations+0.54…+1.85%, p99−0.46…+1.13%. Five confidence intervals still cross a gate. The [older SDK10→net8 matrix](../benchmarks/results/dashboard-overhead-3fafaa2-2026-11-15.html) remains11/12, including off/baseline3nodes64B p99+16.37%, FAIL. The [separate isolated SDK8 control](../benchmarks/results/dashboard-tail-sdk8-2026-11-15.html) also remains available. Neither later result proves a code/compiler cause or universal absence of regression. Cohorts are not pooled or substituted for one another.

The timed workloads use loopback HTTP Standard history, all replicas/client in one process and, for dashboard-on, a separate collector. BFF memory and browser/SSE fanout are excluded from native process allocations. Short cells may omit minute-history writes and repeat file scans. The final full matrix includes the history-capacity, HTTP-display and429-counter changes absent from earlier frozen candidates. Cross-host production load and host certificate revocation policy remain deployment-specific.

The runtime and operational limits in [the runbook](CLUSTER-DASHBOARD.md) still apply. No commit, push, package publication or external deployment is part of this delivery.
