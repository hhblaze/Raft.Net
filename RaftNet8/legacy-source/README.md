# Historical source baseline

These 57 source, project, configuration, and note files were copied from the existing `Raft/` tree on 2026-11-12, excluding generated `bin`, `obj`, `.vs`, and restored package folders. They preserve the implementation and local project-file state present when the resurrection started. They are **not** compiled, tested, or maintained as part of `Raft.Net8.sln`.

The supported implementation is `../src/Raft/`. Its consensus core, storage schema, public API, and wire protocol replace the historical implementation after the [safety review](../../_docs/llm/okf/consensus-audit.md).
