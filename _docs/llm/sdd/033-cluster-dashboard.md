One independent net8.0 ASP.NET/React TypeScript/Ant Design 6/Vite project, RaftClusterDashboard, serves multiple clusters through a backend for frontend. RU/EN, dark/light, actual telemetry. No voting or remote process orchestration. Keep core wire3/raft8-v4 and the accepted embedded performance baseline.

One physical DBreeze table, numeric prefixes, bounded caches, short synchronous transactions. Token secrets never enter the log/snapshot. Read authentication before body allocation and after ReadIndex; write authorization follows log order. Consumer cursors remain application-owned.

Use existing journaled hot membership with operation IDs and explicit Add cancellation. Management intents survive leader changes. Retain entity history and immutable modes; HighSpeedCache remains durable latest plus RAM cache. Management requires credentials even when ordinary client authentication is disabled.

Certificate-free loopback HTTP/TCP defaults are required by the user. Secure profile requires external HTTPS and peer mTLS, host-owned CA/keys, no plaintext fallback. A distinct diagnostic mTLS identity can read node-local health/resources without quorum, never data or mutate. Without that capability, show cached data during quorum loss.

Require privileged MFA in secure profile. Browser never receives service credentials; newly issued client secrets are displayed once.
